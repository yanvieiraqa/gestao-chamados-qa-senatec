# Projeto de QA

Esta pasta reúne os materiais de Garantia da Qualidade (QA) do sistema Gestão de Chamados.

## Escopo

- 44 casos de teste manual
- 36 testes aprovados na primeira execução
- 8 testes reprovados na primeira execução
- 8 bugs registrados e relacionados aos casos de teste
- Planejamento da Sprint 2 — Reteste

## Organização dos materiais

Os casos de teste, resultados e registros de bugs serão organizados nesta pasta. As evidências individuais serão adicionadas conforme forem revisadas e preparadas para publicação.

## Ferramentas

- Jira: planejamento e acompanhamento dos testes
- GitHub: versionamento e apresentação dos materiais do projeto
