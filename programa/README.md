# Programa Gestão de Chamados

Esta pasta será utilizada para organizar o código-fonte da aplicação Gestão de Chamados, desenvolvida em Python com banco de dados SQLite.

## Componentes previstos

- Aplicação principal
- Configurações
- Persistência de dados
- Notificações
- Geração de relatórios
- Funções auxiliares da interface
- Recursos visuais e configuração de empacotamento

## Preparação para publicação

Os arquivos serão adicionados após a revisão do código e de suas dependências, para evitar a publicação de dados privados, bancos com informações reais ou arquivos desnecessários de compilação.
