# Evidências — Casos de Teste

Esta pasta reúne capturas de tela dos casos de teste cadastrados no Jira para o sistema Gestão de Chamados Senatec.

O projeto contém 44 casos de teste, identificados de CT-001 a CT-044, organizados de acordo com os grupos funcionais do sistema.

As imagens demonstram o cadastro e a organização dos casos de teste utilizados na primeira execução dos testes manuais.

As evidências individuais de execução poderão ser consultadas nos respectivos registros do Jira conforme forem anexadas.
